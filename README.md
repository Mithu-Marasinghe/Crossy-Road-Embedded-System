# Possum Simulator

## Set-up:

1. This game can be played either singplayer or multiplayer using UCFunKit
2. First clone the directory using
    - git clone https://github.com/Mithu-Marasinghe/Crossy-Road-Embedded-System.git
3. Then run the command
    - make program
4. If you are playing multiplayer, the command must be run from both devices

## How to Play:

1. On load, there will be a start screen
2. You can proceed by any user clicking the button right next to the screen (D7)
3. Then the game starts!
4. You are a possum declared by a flashing pixel and you can move in any direction using the navswitch
5. There are multiple rows of cars that block a direct path
6. You must weave through these cars to reach the top, in wihch case you will be cross to a new highway with increased car speeds and you can rinse and repeat
7. If a car hits you, you will die!
8. There is also a pesky eagle that monitors both possums waiting for its chance to strike, where if you are more than 10 steps ahead of your opponent you win!
9. This can be seen by how fast the LED is flickering
10. Once the game is either won or lost, a screen displaying the count of wins and losses can be seen
11. You can go back to a new game by simply clicking the D7 button
12. We hope you enjoy and try not to die!!
